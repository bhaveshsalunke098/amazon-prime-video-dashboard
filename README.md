# Amazon Prime Video Movies & TV Shows Dashboard

An interactive **Power BI dashboard** for exploring Amazon Prime Video's content catalog through data visualization and analysis.

## Dashboard Preview

![Amazon Prime Video Dashboard](Amazon%20Prime%20Movies%20and%20TV%20Shows.png)

## Project Overview

This project analyzes Amazon Prime Video movies and TV shows to explore content distribution, ratings, genres, geographical coverage, and release-year trends. The dashboard presents key metrics and visual insights in a single interactive report.

## Key Features

- **KPI Overview:** Total titles, ratings, genres, directors, and release-year range.
- **Ratings Analysis:** Explore the distribution of titles across content rating categories.
- **Genre Analysis:** Identify the most represented genres in the catalog.
- **Country-wise Analysis:** Explore the geographical distribution of content.
- **Content Type Analysis:** Compare movies and TV shows.
- **Release-Year Trends:** Visualize how content distribution changes over time.

## Tools & Technologies

- **Microsoft Power BI** — Dashboard development and visualization
- **Data Preparation** — Preparing and organizing data for analysis
- **Data Visualization** — Charts, KPI cards, and interactive report elements
